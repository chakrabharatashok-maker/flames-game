# 🔥 FLAMES - The Ultimate Couple's Destiny Game 💖

A modern, animated, and interactive couple's web application based on the nostalgic **FLAMES** relationship prediction game (*Friends, Lovers, Affectionate, Marriage, Enemies, Siblings*).

🌐 **Live Demo:** [https://chakrabharatashok-maker.github.io/flames-game/](https://chakrabharatashok-maker.github.io/flames-game/)


---

## 🌟 Key Features

1. **Classic FLAMES Algorithm with 100% Accuracy**:
   - Striking out paired letters one by one between Name 1 and Name 2.
   - Counting remaining uncrossed letters ($N$).
   - Cyclic Josephus elimination on `F-L-A-M-E-S`.
   - Special easter egg for identical letter sets (Twin Flames / Cosmic Soulmates).

2. **Interactive Step-by-Step Romantic Walkthrough Mode**:
   - **Step 1: Letter Tiles Layout**: Displays names as interactive letter badges.
   - **Step 2: Animated Cross-Out**: Cancels paired letters with audio chimes and red pencil slashes.
   - **Step 3: Count Leftovers**: Tallies remaining letters with celebratory badges.
   - **Step 4: FLAMES Elimination Board**: Bouncy flame pointer counts $N$ steps circularly, burning eliminated letters until the winner is found.
   - **Step 5: Grand Reveal**: Confetti cannon, heart explosions, and celebratory fanfare.

3. **Instant Magic Reveal Mode**:
   - Quick one-click calculation for rapid couple checks.

4. **Rich Relationship Profiles & Couple Extras**:
   - **F** – Friends: *The Ride-or-Die Duo*
   - **L** – Lovers: *Written in the Stars*
   - **A** – Affectionate: *Sweet Tender Hearts*
   - **M** – Marriage: *Happily Ever After*
   - **E** – Enemies: *Spicy Frenemies*
   - **S** – Siblings: *Chaos Twins*
   - **T** – Twin Flames: *Cosmic Mirror Soulmates*
   - Compatibility breakdown (Romance, Banter, Vibes, Drama).
   - Dynamic **Truth or Dare Couple Challenges** tailored to the outcome.

5. **Couple Fate Spinner Wheel**:
   - Spontaneous date-night wheel with smooth physics, sector ticks, and confetti.

6. **Couple Polaroid Card Generator**:
   - Generates high-res customized memory card images on an HTML5 canvas and downloads them as PNG.
   - One-click copy formatted text for WhatsApp/Instagram.

7. **4 Beautiful Visual Themes**:
   - 💖 **Cupid's Glow**: Glassmorphism & romantic rose gradients.
   - 📜 **90s School Notebook**: Nostalgic lined notebook paper & doodles.
   - 🌌 **Midnight Galaxy**: Starry dark cyber romance.
   - 🍭 **Candy Pop**: Pastel lavender & bubblegum tones.

8. **Web Audio API Sound Engine**:
   - Zero external audio files required! Synthesizes chimes, ticks, burns, fanfare, and wheel clicks.

9. **Relationship Journal / History**:
   - LocalStorage history log with replay and delete capabilities.

## 🚀 How to Run the Game

You can open `index.html` directly in any web browser, or run a lightweight local HTTP server:

```bash
# Using Python 3
python3 -m http.server 8080
```

Then navigate to `http://localhost:8080` in your web browser.

---

## 🎮 How to Play

1. Enter your name and your partner's / crush's name (choose cute avatars if you like!).
2. Pick **Step-by-Step Story** or **Instant Magic**.
3. Click **"Test Our Destiny! 🔥"**.
4. Watch the letters cross out and the FLAMES wheel eliminate down to your fate.
5. Spin the **Fate Spinner** for a spontaneous couple date activity!
